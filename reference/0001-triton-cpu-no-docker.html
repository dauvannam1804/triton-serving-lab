REFERENCE 0001 · Triton Serving & Performance · xác minh 21/10/2026

Chạy Triton Inference Server CPU-only, không Docker

Công thức đã chạy thành công trên Ubuntu 24.04 (glibc 2.39) với Triton 2.73.0 (nv26.09) — không GPU, không Docker daemon, ~2.1GB disk.

Nguồn chính thức

  • Server zip: GitHub Releases — triton-inference-server/server (từ ~v2.64.0; nội dung zip = thư mục /opt/tritonserver trong container)
  • Quickstart chính thức — xác nhận Triton chạy được CPU-only, cùng image với bản GPU

4 dependency & vai trò

Thành phầnNguồn tảiVì sao cần
tritonserver-*-x86_64.zip (~1.1GB)GitHub ReleasesServer + backends (identity, onnxruntime, pytorch, python, tensorrt…)
libssl3t64 ≥ 3.4 (deb)pool UbuntuBuild Triton 26.09 cần symbol OPENSSL_3.4.0; Ubuntu 24.04 mặc định có OpenSSL 3.0
datacenter-gpu-manager-4-core 4.6.1-1 (deb)NVIDIA cuda repoTriton link cứng libdcgm.so.4 (GPU metrics); không cần driver GPU
nvidia-cuda-runtime + nvidia-cuda-cupti (wheels)pypi.nvidia.comlibcudart.so.13, libcupti.so.13 — zip chỉ chứa libtritonserver.so, CUDA libs lấy từ môi trường

Cài nhanh (script đã có sẵn trong workspace)

./setup_triton_cpu.sh      # tải + giải nén toàn bộ vào ~/.triton-cpu
./serve.sh                 # khởi động server với model_repository/

Khởi động thủ công (hiểu từng thành phần)

export LD_LIBRARY_PATH=\
$HOME/.triton-cpu/ssl_extract/usr/lib/x86_64-linux-gnu:\
$HOME/.triton-cpu/triton_dist/tritonserver/lib64:\
$HOME/.triton-cpu/cuda_libs/nvidia/cu13/lib:\
$HOME/.triton-cpu/dcgm_extract/usr/lib/x86_64-linux-gnu

$HOME/.triton-cpu/triton_dist/tritonserver/bin/tritonserver \
  --model-repository=./model_repository \
  --backend-directory=$HOME/.triton-cpu/triton_dist/tritonserver/backends \
  --http-port 8000 --grpc-port 8001 --metrics-port 8002

3 cổng chuẩn (nhớ bằng: 0-HTTP, 1-gRPC, 2-metrics)

CổngGiao thứcDùng cho

Hạn chế đã biết Không có GPU → GPU metrics trống, pinned memory bị tắt (warning CUDA driver version is insufficient là bình thường). Python backend cần Python 3.12 (stub build cp312). Model TensorRT không chạy được trên CPU.
